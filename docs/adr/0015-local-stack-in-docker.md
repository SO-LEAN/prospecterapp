# 0015. The whole stack runs locally in Docker, driven by make

- Date: 2026-10-14
- Status: Accepted
- Implemented by: cd389ea; `docker-compose.yml`, `Makefile`, `docker/`

## Context

The project needs PHP 8.5, Node 24, pnpm and HTTPS on several hosts (OAuth redirects, CORS, the static host). Installing them on each machine drifts.

## Decision

- Docker services: `php` (FPM and tooling), `node` (Vite dev server), `nginx` serving three HTTPS hosts: `local.prospecter.io` (SPA), `api.local.prospecter.io` (API and sign-in), `static.local.prospecter.io` (images), with a self-signed certificate generated by nginx.
- Nothing but Docker and make on the host; `make install`, `start`, `test`, `test-core`, `e2e`, `lint`, `fix`, `api-doc`, `db`.
- Files created in containers belong to the host user (UID/GID passed by the Makefile).

## Consequences

- One command to get a working stack; the same commands in every environment.
- `/etc/hosts` entries and accepting the certificate once per host are manual.
- Playwright runs in its official image on the host network.

## Alternatives considered

- Symfony CLI and local Node: faster file access, but drifting versions and no shared HTTPS hosts.

## Revisit when

A deployment target exists: align the images with production.
